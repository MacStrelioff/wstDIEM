wstDIEM POC

Mint wstDIEM, provision a Venice key, and start DIEM redemption.

This is a working browser proof-of-concept using local simulated state, a mock DIEM vault, and a mock Venice adapter. It exercises the product flow before any real contract deployment or DIEM spend: deposit mock DIEM, mint mock wstDIEM, create a mock inference key, check mock credits, then initiate mock redemption and view the 24-hour cooldown status.

Live Base MVP

Real wstDIEM contracts are deployed on Base

The live contract flow has been tested with dust DIEM: approve DIEM, deposit into the vault, vault stakes DIEM through the upstream DIEM contract, vault mints non-transferable wstDIEM, then redemption burns wstDIEM and initiates DIEM's 24-hour cooldown. Venice API key automation is intentionally not live yet because contract-staked DIEM attribution still needs Venice-side proof.

Live state is read from Base. Connect a wallet to transact, or refresh to read public vault state.
